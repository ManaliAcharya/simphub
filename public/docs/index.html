Payment Middleware API (1.0.0)

Download OpenAPI specification:

API surface for the modules in this app that currently expose real, working endpoints: Inbound, Payment, Outbound, BookSync, and Boarding.

Not included: Routing, Billing, Reconciliation, Audit, and TrustAccounting modules each have a routes/api.php file (per the module-per-domain convention documented in CLAUDE.md) but currently contain only placeholder route groups with no endpoints registered inside them. The Auth module's /api/v1/auths CRUD routes are also excluded — they're gated by auth:sanctum, but laravel/sanctum is not installed in this project (absent from composer.json/composer.lock), so that route currently errors if hit and is not a usable API today.

Authentication is not uniform across modules — see the security scheme descriptions below and the per-operation security blocks. Several endpoint groups (Payment session endpoints, Outbound direct/terminal endpoints) have no authentication middleware at all; security there relies entirely on the unguessability of the token/ID in the URL.

Authentication

Inbound CRM API

/api/v1/invoices*, /api/v1/transactions*, /api/v1/refunds, /api/v1/clients/{client_id}/email-config*

Authorization: Bearer <pms_client_id>

The bearer token is the client's pms_client_id — there is no separate API-key value to generate. {client_id} in the URL path is accepted but ignored; the client is always resolved from this header.

Other modules (BookSync, Boarding, Payment, Outbound) use their own, different auth schemes — see each operation's security block below.

Inbound - Webhooks & Ingestion

PMS webhook receivers and raw invoice ingestion. Unauthenticated by design (PMS providers call these directly).

Receive a PMS webhook event

Dispatches to a per-PMS webhook service based on {source}. Each service (Clio/Zoho/QuickBooks/Lawcus/Wave) owns its own request body shape and signature verification — not modeled here since it varies per provider. An unrecognized source value is accepted (202) but not processed.

required
string
Enum: "clio" "zoho" "quickbooks" "lawcus" "wave"
